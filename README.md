## ✨ What is this?

**Study Bloom** is a full-stack academic planner built for exam season — track every subject's syllabus coverage, watch live countdowns to exam day, and organize daily study sessions on a drag-and-drop board. It's wired end-to-end to **Supabase**, so your data is real, persistent, and yours alone (Row Level Security keeps every user's planner private).

No clutter, no cold spreadsheet vibes — just a warm, blush-and-lilac workspace that makes opening your planner feel like a treat instead of a chore. 🎀

## 💖 Features

| | |
|---|---|
| 🌷 **Dashboard Overview** | A glanceable home base — overall syllabus progress ring, today's task completion, and upcoming exam countdowns, all in one view |
| ⏳ **Live Exam Countdowns** | Color-coded urgency badges (Urgent / Soon / Upcoming) that update in real time as exam day approaches |
| 📚 **Exam Tracker** | Add subjects, set exam dates, and drag a slider to update syllabus coverage on the fly |
| 🗂️ **Kanban Daily Scheduler** | Drag-and-drop tasks across To Do → In Progress → Done, with priority tags and time blocks |
| 🔐 **Full Authentication** | Email + password auth via Supabase, with each user's data isolated by Row Level Security |
| 🎨 **Girly Glassmorphism UI** | Soft blush + lilac gradients, rounded-3xl cards, tinted pink shadows, and buttery Framer Motion micro-interactions |
| 📱 **Fully Responsive** | Sidebar nav on desktop, bottom tab bar on mobile — no feature left behind on smaller screens |
| ⚡ **Real CRUD, Real Backend** | Every add/edit/delete hits Supabase directly — nothing is faked or stored in local state alone |
